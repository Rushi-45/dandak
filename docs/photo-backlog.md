# Photo backlog

**78 of 106 spots have no photograph.** 28 are done (26%).

In travel search results the thumbnail drives click-through harder than anything
in the text, and these are places you have actually been. This is the highest-value
work left on the project.

Generated by `npm run photo-backlog` — regenerate after adding photographs rather
than editing by hand.

## How to read it

Each run starts from a base town and is ordered by **road** distance from it, so
working down a list is roughly working outward. Straight-line distances would
mislead here: Ahwa to Chikhalda is 12 km on a map and 54 km on the road.

- **★** marks a spot with no competing coverage anywhere — every source is a map
  pin, a vlog or your own visit. A photograph of these is worth several of the rest,
  because the page can rank first on the strength of being the only real answer.
- **Season** is the window the record itself declares. Monsoon-fed falls outside it
  are a dry rock face, so a trip in the wrong month is wasted.
- Coordinates are given to paste straight into a maps app.

## While you are there: fix the coordinates too

None of these 78 records has an `exact` coordinate — they are 32 `approximate`, 46 `area`.
A GPS fix taken at the spot costs nothing on top of the photograph and upgrades
`location.coordinates.precision` to `exact`, which is what makes the map and the
trip planner trustworthy. Take the reading at the viewpoint or the parking place,
whichever a visitor actually needs, and say which in `access.last_mile`.

## Adding a photograph

1. Drop the file at `web/public/images/spots/<spot-id>.jpg` — the **id**, not the
   slug. They differ more often than you would expect: Karanjwa Waterfall is
   `dang-mahal-falls`, Rajpipla Old Town is `narmada-rajpipla-heritage-walk`. The id
   is the `id` field of the record. Extra angles are `<spot-id>-2.jpg`, `-3.jpg`.
2. Add a matching entry to `media.images` in the record, **in the same order**.
   Pairing is strictly by index — `media.images[0]` describes `<id>.jpg`,
   `media.images[1]` describes `<id>-2.jpg`. Your own photographs take
   `"license": "own"`; anything from Commons carries its own licence, the
   photographer's name in `credit`, and a `source_url`.
3. Run `npm run validate`. A declared count that disagrees with the staged count
   raises a warning — and it matters more than the word suggests, because a surplus
   entry silently hands its credit to the next photograph added. That is an
   attribution problem, not an untidiness. Warnings only fail the run under
   `--strict`, so read the output rather than trusting the exit code.
4. Check every frame for identifiable faces before it is published. These are
   inhabited villages, not scenery.
